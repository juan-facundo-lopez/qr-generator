GeneraQR

GeneraQR is a lightweight web application that allows users to instantly generate custom QR codes from text, links, or other input data.
The project focuses on simplicity, speed, and a clean user experience, making QR creation accessible without unnecessary complexity.

Live demo https://unkiwi.com.ar/generaqr/

Features
Generate QR codes instantly
Clean and responsive interface
Fast client-side rendering
Mobile-friendly experience
Minimal and lightweight design
Easy to use for links, text, contact info, and more
Technologies Used
HTML5
CSS3
JavaScript (Vanilla JS)
QR Code generation library
Responsive web design principles
Project Goals

The idea behind GeneraQR was to create a minimal tool that solves a very common need in a fast and intuitive way.
Instead of building a complex platform, the goal was to focus on:

usability
speed
visual clarity
accessibility across devices
Design Approach

The UI was designed with a minimalist approach, prioritizing:

clean spacing
strong readability
low friction interaction
responsive behavior
modern visual aesthetics
